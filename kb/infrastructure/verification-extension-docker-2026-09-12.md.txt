## 功能

- 授权码激活、设备绑定、设备上限、过期、暂停/恢复、撤销设备。
- 插件未激活时不运行自动化。
- 目标域名白名单和 `authorized_simulation` 页面标记。
- OCR API 只允许激活设备调用；输入 data URL 只解码一次，限制 2MB。
- 自学习：按域名记录 kind/selector/action 成功与失败次数；插件按成功率优先复用策略；不上传密码、Cookie、challenge token。
- 模拟生产验证能力：OAuth、Turnstile/hCaptcha 控件、图片 OCR、算术、Canvas、动态 DOM、Shadow DOM、滑块、拼图、顺序点选、旋转。
- Hassbian/Discuz 兼容：识别 `input[name="seccodeverify"]`、`id^="seccodeverify_"` 和同一验证码行内无 `alt` 的 `misc.php?mod=seccode` 动图；GIF 优先走 HTTP 缓存 + `ImageDecoder` 取最长停留帧，缓存未命中则截当前页可见帧，**禁止二次 fetch**（Discuz `no-cache` 会换码）；同一签名只提交一次；动态登录弹窗与验证码 `src` 刷新由 MutationObserver 触发处理；用户名/密码为空时只填验证码不自动提交；账号密码后填时由 input/change 监听继续提交。

## 管理 UI 创建授权修复

- 修复创建授权时报 `Cannot read properties of undefined (reading 'trim')`：根因是表单 `id="name"` 依赖元素全局变量，与浏览器内置 `window.name` 冲突；现改为全部使用显式 `document.getElementById` 引用。
- 新增“永久授权”复选框；勾选后有效天数输入框禁用，创建请求发送 `permanent: true`，后端把 `expires_at` 保存为 `NULL`，列表和创建结果显示“永久”。
