编辑全站公告优化（2026-07-25）

背景

公告弹窗此前存在：打开函数缺失/字段回填不全、画布编辑模式函数缺失、底部操作不便、草稿感知弱、发布无防重复提交。

已优化

  1. 打开加载 - 完整回填字号/对齐/位置/横幅/版本/定向/定时字段 - 加载中 toast + 侧栏防连点 - 草稿检测：可一键「载入草稿 / 保留线上版」
  2. 编辑体验 - 补齐 setAnnouncementEditorMode(canvas|html) - 工具栏 B/I/U/对齐在 HTML 与画布模式均可用
  3. 发布链路 - 空内容校验 - 发布二次确认 - 按钮 busy/禁用防重复提交 - 草稿/预览/发布反馈更明确
  4. 布局 - sticky 顶栏 + 底部操作栏 - 表单区独立滚动 - 手机端全宽与按钮折行
  5. 快捷键 - 弹窗打开时 Ctrl/Cmd+S 保存草稿

验证

  • dashboard 主脚本 node --check 通过
  • /api/admin/announcement GET success
  • verify_all ready=true

使用

后台 Ctrl+F5 后点「编辑全站公告」。
