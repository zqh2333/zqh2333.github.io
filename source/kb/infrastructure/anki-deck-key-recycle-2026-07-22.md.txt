# 牌组专属密钥回收站（2026-07-22）

## 需求
在「牌组专属密钥管理」增加与激活码类似的软删除回收站：删除可恢复，永久删除才真正清除。

## 实现
### 模型
- `DeckKeyRecycle` 表 `deck_key_recycle`
  - `deck_id` / `deck_name` / `snapshot(JSON)` / `delete_reason` / `deleted_at`
  - 快照含 `deck_key`、原 meta 状态等，恢复时写回 `decks` + `deck_key_meta`

### 删除路径全部改为软删
| 操作 | 原因码 |
|---|---|
| 单删 `/api/admin/decks/<id>` | `single_delete` |
| 批量 `/api/admin/delete_decks` | `bulk_delete` |
| 全清 `/api/admin/delete_all_decks` | `delete_all` |
| 按日期 | `delete_by_date` |
| 智能清理历史版 | `cleanup_old` |

删除时：写入回收站 → 主表 `decks` 移除 → `deck_key_meta.status=recycle`（保留历史，不硬删 meta）。

### 专用 API
- `GET /api/admin/deck_key_recycle_bin`
- `POST /api/admin/deck_key_recycle_restore/<id>`
- `DELETE /api/admin/deck_key_recycle/<id>`（需 `confirm=PERMANENT_DELETE_RECYCLED_DECK_KEY`）
- 通用 `/api/admin/recycle_bin` / `recycle_restore` 也识别 `deck_key_recycle`

### 前端
`templates/dashboard.html` 牌组模态框：
- 工具栏「🗑 密钥回收站」+ 计数徽章
- 面板：列表 / 恢复 / 永久删除
- 打开牌组管理时静默刷新徽章
- 文案改为“先入回收站”

## 验证
容器内 E2E（临时 `DK-AUDIT-RECYCLE-001`）：
1. 创建 → 软删 → 列表有记录
2. 恢复 → `decks` 与 `deck_key` 还原
3. 再软删 → 永久删除 → 主表与回收站均空
4. 未登录 302
5. `verify_all.py` success/ready

备份：`*.bak_deck_recycle_20260722`

## 使用
后台 → 牌组专属密钥管理 → 删除密钥 → 点「密钥回收站」恢复或永久删除。
