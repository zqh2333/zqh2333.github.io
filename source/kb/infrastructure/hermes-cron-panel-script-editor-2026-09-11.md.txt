# Hermes Cron 青龙式脚本管理面板

- 日期：2026-09-11
- 目标：在不替换 Hermes 原生 cron 调度器的前提下，提供接近青龙面板的任务与脚本操作界面。
- 面板文件：`~/.hermes/scripts/hermes_cron_panel.py`
- 服务：`hermes-cron-panel.service`，监听 `0.0.0.0:8421`。

## 功能

- 定时任务：列表、搜索、按成功/失败/暂停筛选、后台运行、日志、编辑、暂停/恢复、删除。
- 脚本管理：脚本列表、大小/更新时间/权限/绑定任务、查看、新建、编辑、保存、删除。
- 保存脚本前执行 `python3 -m py_compile` 或 `bash -n` 语法检查。
- 保存已有脚本前自动备份到 `~/.hermes/scripts/.panel_backups/`。
- 删除脚本采用移动到备份目录；启用任务仍引用该脚本时拒绝删除。

## 安全边界

- 脚本路径限制为 `~/.hermes/scripts/` 根目录下的 `.py`、`.sh`、`.bash` 文件名，拒绝路径穿越和 shell 字符。
- 脚本编辑上限 300KB。
- 面板继续使用账号密码登录，密码为 PBKDF2 哈希，session token 仅存内存。
- 移除旧版 systemd `EnvironmentFile` token URL 配置及旧 token 文件；当前只使用账号密码登录。

## 验证

- `py_compile` 通过。
- systemd 服务 active。
- 未登录 `/api/jobs` 返回 HTTP 401。
- 错误密码返回 401；正确登录返回 200。
- `/api/jobs` 返回真实任务 12 条；`/api/scripts` 返回真实脚本 32 条。
- 脚本新建、读取、更新、语法检查、删除闭环通过；烟测脚本已移入备份目录，无残留活动脚本。
- 浏览器验证面板标题为“Hermes Cron 青龙面板”；登录后任务统计加载；切换“脚本管理”成功，真实脚本内容加载，控制台无错误。
