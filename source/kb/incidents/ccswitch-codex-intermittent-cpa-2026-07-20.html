CC Switch + Codex 经 CPA 间歇失败（2026-07-20）

症状

  • CC Switch 开 Codex 模式走 CPA 时，一会儿能用一会儿不能用
  • 上游站控制台看模型列表正常
  • 上游公告：禁止 CPA/sub/new-api 等分发工具、禁止 agent 大报文

根因（日志 + 本地验证，未做上游探活）

间歇失败不是 8317 白名单/服务挂掉，而是上游业务拒绝 + 冷却后池空：

错误 含义
auth_unavailable: no auth available 该模型可用上游凭据都在冷却/不可用
403 insufficient balance 上游余额不足
403 全站额度已用完，请 18:00 后再试 公益站全站窗口额度（Codex/gpt-5.4）
403 带 HTML 诊断页 上游反滥用/配额拒绝
429 concurrency/rate limit 上游并发或限流
502 timed out 长会话或上游慢
UI 选 Grok 却报 model: gpt-* CC Switch 会话/映射，非 edge 归一

已做修复

  1. Hermes fallback 对齐菜单：grok-4.5 → gpt-5.5 → gpt-5.6-terra → glm-5.2 → deepseek-v4-pro → mimo-v2.5-pro
  2. abrdns 模型名大小写归一到裸名
  3. cpa-stable-proxy chat 超时 180s → 300s
  4. RawChat 桥与 stable-proxy 均为 active

验证（本地 8317 最小业务句）

  • grok-4.5 chat + /responses → 200
  • gpt-5.5 → 503 池暂不可用
  • gpt-5.4 → 403 时段额度
  • gpt-5.6-terra → 403 余额

CC Switch 用法

Base http://<LAN-8>:8317/v1；裸名；新开对话；额度满时间歇失败是上游策略。
