首次激活却提示 RISK_LOCKED「江西→北京」（2026-07-24）

用户反馈

  • 苹果手机第一次激活
  • 激活码 BDF3G5729UCX 后台 0 设备
  • 却提示：轨迹瞬移 4 小时内由江西突变至北京（RISK_LOCKED）

根因

  1. 激活码 BDF3G5729UCX 确实从未绑定设备。
  2. 该 iPhone 的 device_id=HW-9993F969E659AB20FB0686CD（hash 07cc95e6c3）已绑定其它激活码 R6RQFDXQEGJE（设备 id 754）。
  3. 静默校验在无 code_input 时用 全局 device_id 命中这台旧设备，继承了其 ip_history 上的 risk_locked（江西→北京）。
  4. 因此对「本码未激活」的用户展示了别的码的 IP 轨迹。

修复

  • 静默无码路径：若命中设备存在 risk_locked 或 IP 高风险，改为返回 AUTH_REQUIRED「请输入激活码」，不再展示外码轨迹文案。
  • Worker：移动/电信/联通/教育网等运营商 IP 不再因省际跳变写 risk_locked（仅机房类 ISP 保留）。
  • 已清理 7 台设备的错误 risk_locked 标记（含设备 754）。
