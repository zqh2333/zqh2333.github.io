# 指定 IP 段开放端口扫描（port_scan.py）

- 日期：2026-09-29
- 类型：runbook
- 脚本：`~/.hermes/scripts/port_scan.py`（v1.0.0，仅标准库，无需 pip/venv）

## 目标 / 场景

需要快速摸清某段内网或某台设备开放了哪些端口（新增服务、暴露面核对、拓扑巡检前置步骤）。
本机 Python 为 PEP 668 且无 pip，因此脚本只用标准库，可直接 `python3` 运行。

## 用法

```bash
# 默认 top 端口集扫一个 C 段
python3 ~/.hermes/scripts/port_scan.py <LAN-0>/24

# 指定端口 + 超时 + 抓 banner
python3 ~/.hermes/scripts/port_scan.py <LAN-8> -p 22,80,443,8317 --banner --timeout 0.8

# 区间与末位简写混合，输出 JSON 到文件
python3 ~/.hermes/scripts/port_scan.py <LAN-1>-50,<LAN-8> -p 1-1024,8317 -q -f json -o /tmp/scan.json

# 主机清单文件（每行一个，# 开头为注释）
python3 ~/.hermes/scripts/port_scan.py -t hosts.txt -p top

# UDP（无响应记为 open|filtered，无 root/ICMP 时无法进一步区分）
python3 ~/.hermes/scripts/port_scan.py <LAN-8> -p 53,161,1883 --udp --banner

# 供 cron/告警使用：无开放端口时退出码 1
python3 ~/.hermes/scripts/port_scan.py <LAN-8> -p 8317,5700,5778 -q --fail-if-none
```

目标写法：单机 / CIDR / `a-b` 完整区间 / `10.0.0.1-50` 末位简写 / 主机名，逗号可混合。
端口写法：`22,80` / `1-1024` / `top` / 混合。
输出：`text`（按主机分组，默认）/ `json` / `csv`；进度与命中实时打到 stderr，结果打到 stdout。

## 关键实现决策

1. **纯标准库并发**：`ThreadPoolExecutor` 做 connect 扫描（默认 256 线程），不用 scapy/raw socket，
   因此普通用户即可运行，也不需要 root。
2. **服务名不采信 `/etc/services`**：本机 `getservbyport` 会把 443 解析成 `microsoft-ds`、
   139 解析成 `http`、8080 带注释换行。脚本内置 `WELL_KNOWN` 权威表覆盖常见端口
   （含本环境端口：`5700=qinglong`、`5778=anki-web`、`8317=cpa-proxy`、`18317=cpa-docker`、`8006=pve-web`），
   其余回落系统表并做 `#` 注释与空白清洗。
3. **误扫保护**：主机数默认上限 4096，超过直接拒绝（退出码 3），需显式 `--max-hosts`。
   `10.0.0.0/8` 这类会被拦下，避免误触大网段。
4. **单点失败不中断整轮**：单端口探测异常只记入 `errors`，不影响其余结果。
5. **退出码**：0 正常；1 `--fail-if-none` 且无开放端口；2 参数/解析错误；3 目标过大；130 中断。

## 验证方式与结果（真实回归）

在本机起真实监听（http.server:8099、自制 TCP:18022/18023、UDP echo:18024），再用脚本回扫：

- `127.0.0.1 -p 8099,18022,18023,18024 --banner` → 精确命中 3 个 TCP 端口，
  并抓到 banner `SSH-2.0-OpenSSH_9.6p1 test`；`--udp` 命中 18024 且抓到 `UDP-ECHO-OK`。
- CIDR `127.0.0.0/30` 展开 2 个可用地址、`127.0.0.1-3` 末位简写展开 3 个地址，均正确。
- JSON/CSV 输出字段完整；`-p 1-10 --fail-if-none` 返回退出码 1。
- 大网段 `10.0.0.0/8` 被拒（退出码 3）；越界端口 `70000` 报错（退出码 2）。
- 真实内网 `<LAN-1>-10 -p top`：1.5s 内扫完 880 个组合，命中 42 个开放端口，
  与已知拓扑一致（`.1` PVE 8006、`.2/.6` DNS 53、`.8` 青龙 5700 + Anki 5778 + CPA docker 18317）。

## 边界与注意

- 只用于自有或已获授权资产；**禁止**对 CPA 上游站点等第三方做探测（用户硬规则）。
- UDP 结果只有 `open` 与 `open|filtered` 两态，无 root 时收不到 ICMP port unreachable，不能判定 closed。
- 扫描是 connect 扫描，会在目标留下连接记录（不同于 SYN 半开扫描）。
